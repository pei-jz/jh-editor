水墨画テーマ候補
この提案の方針
ご要望の「白黒」を徹底し、既存の黄系（Paper / 竹簡 / Sumi-e）とは方向を分けました。 色は墨の濃淡（墨分五色）だけのモノクロ構文。 背景の「山水画（遠山・滝・小舟・松）」は下端に淡墨で寄せ、文字が主役を崩しません。上部はフェードで本文領域をクリアに保ちます。 朱印は唯一の色（省略すれば完全モノクロ）。

水墨画（墨絵）エディタテーマ提案

中国の水墨画を「白黒モノクロ・目に優しい・文字が邪魔にならない」の3条件で設計しました。 純白ではなく生宣紙の温かい白と、純黒ではなく墨の柔らかい黒で眩しさを抑え、 構文ハイライトは色相を一切使わず「墨分五色」の濃淡だけで階層を出します。背景は下端に淡墨の山水画（遠山・滝・小舟・松）を描き、上部はフェードで文字の可読性を確保しています。
