# LargeFileView.js — 巨大ファイル専用表示ビューア

## 概要
100MB超のテキストファイルを表示・検索・集計する読み取り専用ビューアです。Textareaは使用せず、仮想化された行レンダリングで高速表示を実現します。

## ファイル情報
- **パス**: `src/modules/views/LargeFileView.js`（559行）
- **依存**: `@tauri-apps/api/core`(invoke)

## 主要機能

| 機能 | 説明 |
|------|------|
| メモリモード | ファイル全体をJS文字列で保持 |
| バックエンドモード | Rust mmapから行を都度取得 |
| 仮想化表示 | 画面外の行は非表示 |
| 検索 | バックエンド検索 |
| 集計 | 行数、文字数、バイト数 |
| 編集モード切替 | LargeFileEditViewへの遷移 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| ファイルサイズ < 安全閾値 | メモリモード |
| ファイルサイズ >= 安全閾値 | バックエンドモード |
| 行キャッシュ超過 | 古いキャッシュ削除 |
