# Search.js — 検索・置換システム

## 概要
ファイル内検索・置換システム。正規表現、大文字小文字区別、単語単位検索、正規表現テンプレートをサポートします。

## ファイル情報
- **パス**: `src/modules/ui/Search.js`（921行）

## 主要機能

| 機能 | 説明 |
|------|------|
| 検索パネル | Ctrl+Fで表示 |
| 置換モード | Alt+Pで切替 |
| 正規表現 | Alt+Eで切替 |
| 大文字小文字区別 | Alt+Cで切替 |
| 単語単位検索 | Alt+Wで切替 |
| 正規表現テンプレート | Alt+Tで表示 |
| 一括置換 | Alt+A |
| 置換して次へ | Alt+Enter |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 検索結果0件 | 「見つかりません」表示 |
| CSVグリッドモード | CSV固有のセル単位検索に切替 |
| ファイル未開き | 検索無効 |
