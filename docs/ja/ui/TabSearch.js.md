# TabSearch.js — タブ検索・切替

## 概要  
Ctrl+Tで表示されるオープンタブの検索・切替モーダルです。

## ファイル情報
- **パス**: `src/modules/ui/TabSearch.js`（95行）
- **依存**: `Store.js`

## 主要機能

| 機能 | 説明 |
|------|------|
| タブ一覧表示 | 開いている全タブを一覧 |
| リアルタイムフィルタ | 入力中リアルタイムでフィルタリング |
| 選択して切替 | Enterで選択タブに切替 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| タブなし | 空リスト表示 |
| フィルタ結果0件 | 「一致なし」表示 |
| Escapeキー | モーダル閉じる |
