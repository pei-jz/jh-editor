# ShortcutGuide.js — キーボードショートカットリファレンス

## 概要
キーボードショートカットの一覧を表示するガイドパネルです。

## ファイル情報
- **パス**: `src/modules/ui/ShortcutGuide.js`（163行）
- **依存**: `ShortcutManager`, `ShortcutDefinitions`

## 主要機能

| 機能 | 説明 |
|------|------|
| ショートカット一覧表示 | スコープ別にグループ化 |
| 検索フィルタ | キーワードでフィルタリング |
| 表示/非表示切替 | F1またはCtrl+?でトグル |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| フィルタ語句あり | 説明で一致するもののみ表示 |
| フィルタ語句なし | 全ショートカット表示 |
| ユーザーカスタマイズ適用中 | 変更済みマーク表示 |
