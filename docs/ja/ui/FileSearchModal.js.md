# FileSearchModal.js — グローバルファイル検索

## 概要
globパターン対応のグローバルファイル検索モーダルです。

## ファイル情報
- **パス**: `src/modules/ui/FileSearchModal.js`（365行）
- **依存**: `@tauri-apps/api/core`(invoke), `Store.js`

## 主要機能

| 機能 | 説明 |
|------|------|
| ファイル名検索 | globパターン対応 |
| ファイル内容検索 | テキストgrep |
| リアルタイム結果 | 入力中にリアルタイム更新 |
| ファイルを開く | 選択ファイルを開く |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| パターンが空 | 空リスト表示 |
| ワークスペース未設定 | ダイアログでフォルダ選択を促す |
| 結果数超過 | 上限件数で切捨て |
