# OutlineModal.js — ドキュメントアウトラインナビゲーション

## 概要
現在のMarkdownファイルの見出し構造をアウトラインとして表示し、ナビゲーションできるモーダルです。

## ファイル情報
- **パス**: `src/modules/ui/OutlineModal.js`（248行）
- **依存**: `marked.js`

## 主要機能

| 機能 | 説明 |
|------|------|
| 見出し抽出 | MarkdownからH1-H6を抽出 |
| 階層表示 | ネストされた見出し構造 |
| クリックジャンプ | 見出しがある行にスクロール |
| Ctrl+Oで表示 | ショートカット対応 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 見出しなし | 「見出しがありません」表示 |
| ファイル未開き | 無効化 |
| Ctrl+Enter | 選択見出しにジャンプ |
