# ContextMenu.js — 右クリックコンテキストメニュー

## 概要
サブメニュー対応の右クリックコンテキストメニューを提供するシングルトンオブジェクトです。

## ファイル情報
- **パス**: `src/modules/ui/ContextMenu.js`（135行）

## 主要機能

| 機能 | 説明 |
|------|------|
| `show(items, x, y)` | メニューを表示 |
| `hide()` | メニューを非表示 |
| サブメニュー | ネストされたサブメニュー表示 |
| ディスエーブル | 無効なアイテムのグレーアウト |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| アイテムに`disabled: true` | グレーアウト表示、クリック無効 |
| アイテムに`children` | サブメニューアローアイコン表示 |
| メニューが画面外にはみ出し | 位置調整 |
| クリップボードAPI未使用 | 「コピー」無効 |
