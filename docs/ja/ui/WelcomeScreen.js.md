# WelcomeScreen.js — ウェルカムスクリーン

## 概要
アプリケーション起動時に表示されるウェルカムスクリーンです。ワークスペース選択と最近のワークスペース一覧を提供します。

## ファイル情報
- **パス**: `src/modules/ui/WelcomeScreen.js`（121行）

## 主要機能

| 機能 | 説明 |
|------|------|
| フォルダを開く | ネイティブダイアログでフォルダ選択 |
| 最近のワークスペース | localStorageから最近のワークスペースを表示 |
| ワークスペース切替 | 選択したワークスペースに切り替え |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| ワークスペース選択済み | ウェルカムスクリーン非表示 |
| 最近のワークスペースなし | 「最近のワークスペース」セクション非表示 |
| フォルダ選択キャンセル | 何もしない |
