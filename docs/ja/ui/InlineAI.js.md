# InlineAI.js — インラインAIアシスタント

## 概要
選択テキストに対するインラインAIアシスタントポップアップです。Ctrl+Spaceでトリガーされ、LLMによるテキスト編集提案を表示します。

## ファイル情報
- **パス**: `src/modules/ui/InlineAI.js`（503行）
- **依存**: `AIAgent`, `DiffEditor`

## 主要機能

| 機能 | 説明 |
|------|------|
| AI提案 | 選択テキストに対する編集提案 |
| 差分表示 | DiffEditorで変更差分を表示 |
| 受入/拒否 | 提案の適用/キャンセル |
| コンテキスト | 周囲テキストをコンテキストとして送信 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| テキスト未選択 | 全バッファをコンテキストとして使用 |
| AIレスポンスエラー | エラーメッセージ表示 |
| レスポンスに変更なし | 「変更なし」メッセージ表示 |
