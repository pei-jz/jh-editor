# SettingsModal.js — 設定ダイアログ

## 概要
アプリケーション設定を管理するダイアログです。テーマ、フォント、ビューモード、キーバインド、AI設定を提供します。

## ファイル情報
- **パス**: `src/modules/ui/SettingsModal.js`（578行）

## 主要関数

| 関数 | 説明 |
|------|------|
| `initSettingsModal()` | 設定モーダル初期化 |
| `applyTheme(theme)` | テーマ適用 |
| `show()` | モーダル表示 |
| `hide()` | モーダル非表示 |

## 設定タブ

| タブ | 設定項目 |
|------|---------|
| General | テーマ、ビューモード、フォント、フォントサイズ |
| Agent | AI接続設定 |
| Keybindings | ショートカットカスタマイズ |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| テーマ変更 | CSSカスタムプロパティを即時更新 |
| フォントサイズ変更 | ラインハイトを自動計算 |
| キーバインド記録 | `_isRecordingShortcut`フラグでShortcutManagerと連携 |
| 保存ボタン | localStorageに全設定を保存し適用 |
