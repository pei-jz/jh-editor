# GitPanel.js — 完全なGit統合パネル

## 概要
`GitPanel`はJHEditorのGit統合UIです。ステータス表示、差分表示、コミット、プッシュ、プルなど完全なGit操作を提供します。

## ファイル情報
- **パス**: `src/modules/ui/GitPanel.js`（約1060行）
- **依存**: `@tauri-apps/api/core`(invoke), `ContextMenu`

## 主要機能

| 機能 | 説明 |
|------|------|
| `git_status` | ブランチ、ステージド、修正、**削除**、追跡未設定ファイル表示 |
| `git_diff` | ファイル差分の表示 |
| `git_add` / `git_unstage` | ステージング/アンステージ |
| `git_commit` | コミット |
| `git_push` / `git_pull` / `git_fetch` | リモート操作 |
| `git_log` | コミット履歴 |
| `git_discard` | 変更の破棄（削除ファイルは復元） |
| `git_ignore` | .gitignore追加 |
| `git_init` | リポジトリ初期化 |

## ステータス表示の詳細

### 変更一覧（CHANGES）の分類
- **M（Modified）**: 作業ツリーで変更されたファイル
- **D（Deleted）**: 作業ツリーで削除されたファイル。バッジは赤色＋ラベルに打ち消し線を表示し、「削除」を明示
- **U（Untracked）**: 新規追加されたファイル/フォルダ

### Untracked フォルダの扱い
- Rust側の `git_status` は `-uall` オプションで untracked ディレクトリ内の全ファイルを個別に列挙する
- これにより `docs/` のような新規フォルダはツリーのフォルダノードとして表示され、展開すると中身のファイルが見える
- 空の untracked フォルダはフォルダノードとして表示され、ステージボタンから一括ステージ可能

### ステータスバッジ
- `U`（緑）: 新規追加（Untracked）
- `M`（黄/橙）: 変更（Modified）
- `D`（赤）: 削除（Deleted）— 打ち消し線つき
- `S`（緑）: ステージ済み（Staged）

バッジにマウスを乗せると、各コードの意味を示すツールチップが表示される。

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| Gitリポジトリ未検出 | 「Git初期化」ボタン表示 |
| ステージドファイルなし | コミットボタン無効 |
| プッシュ/プルエラー | エラーメッセージ表示 |
| マルチリポジトリ | リポジトリ切替UI表示 |
| 削除ファイルの差分表示 | HEADの内容（左）と空（右）を差分表示 |
| untrackedフォルダ | ツリーノードとして表示し、ステージ可能 |
