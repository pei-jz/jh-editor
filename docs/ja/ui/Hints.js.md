# Hints.js — Vimiumスタイルリンクヒント

## 概要
Vimiumスタイルのリンクヒントを表示します。ブラウザ内のインタラクティブ要素にラベルを付けて、キーボードで操作可能にします。

## ファイル情報
- **パス**: `src/modules/ui/Hints.js`（265行）

## 主要機能

| 機能 | 説明 |
|------|------|
| `showHints()` | インタラクティブ要素にヒントラベルを表示 |
| キーボード選択 | ヒントラベルをタイプして要素を選択 |
| ESCキャンセル | 全ヒントを非表示 |

## 対象要素

`a`, `button`, `input`, `textarea`, `[tabindex]`, `[onclick]`

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 要素が画面外 | ヒント非表示 |
| 要素が`display:none` | スキップ |
| キーがヒント文字列と一致 | その要素をクリック |
