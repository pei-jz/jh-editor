# DiagnosticsOverlay.js — LSP診断オーバーレイ

## 概要
LSP診断情報（エラー、警告）をエディタ上にオーバーレイ表示するコンポーネントです。

## ファイル情報
- **パス**: `src/modules/lsp/DiagnosticsOverlay.js`（7.5KB）
- **依存**: `LspClient`, CodeMirror

## 主要機能

| 機能 | 説明 |
|------|------|
| 診断表示 | 行単位でエラー/警告アイコンを表示 |
| ホバー詳細 | マウスオーバーで診断メッセージ表示 |
| アンダーライン | エラー箇所に赤/黄色のアンダーライン |
| 自動更新 | ファイル変更時に再取得 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 診断なし | オーバーレイ非表示 |
| エラー | 赤アイコン + 赤アンダーライン |
| 警告 | 黄アイコン + 黄アンダーライン |
| 情報 | 青アンダーライン |
