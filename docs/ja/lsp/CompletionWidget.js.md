# CompletionWidget.js — LSP補完ウィジェットUI

## 概要
LSP補完候補を表示するウィジェットUIです。

## ファイル情報
- **パス**: `src/modules/lsp/CompletionWidget.js`（3.2KB）
- **依存**: `LspClient`

## 主要機能

| 機能 | 説明 |
|------|------|
| 補完候補表示 | ドロップダウンで候補一覧 |
| キーボードナビゲーション | 矢印キーで候補移動 |
| 選択確定 | Enterで候補を適用 |
| キャンセル | Escapeで候補リスト非表示 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 候補0件 | ウィジェット非表示 |
| 候補1件でプレフィックス一致 | 自動適用 |
| 入力文字列変更 | 候補リスト再フィルタ |
