# HoverWidget.js — LSPホバーウィジェット

## 概要
LSPホバー情報を表示するウィジェットです。マウスカーソルをシンボルの上に置くと表示されます。

## ファイル情報
- **パス**: `src/modules/lsp/HoverWidget.js`（2.5KB）
- **依存**: `LspClient`

## 主要機能

| 機能 | 説明 |
|------|------|
| ホバー表示 | シンボルの型情報・ドキュメントを表示 |
| マークダウンレンダリング | ホバー内容のMarkdown表示 |
| 位置調整 | ウィンドウ内に収まるよう位置調整 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| ホバー情報なし | ウィジェット非表示 |
| ドキュメント過大 | トランケート表示 |
| ウィンドウ端近辺 | 位置反転表示 |
