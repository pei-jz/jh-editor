# VirtualScroll.js — 仮想スクロールエンジン

## 概要
`VirtualScroll`は大量のDOM要素を効率的にレンダリングするための仮想スクロールエンジンです。CsvEditor等で使用されます。

## ファイル情報
- **パス**: `src/modules/utils/VirtualScroll.js`（3.6KB）

## 主要機能

| 機能 | 説明 |
|------|------|
| 行の仮想化 | 画面外の行はDOMに存在しない |
| カラムの仮想化 | 画面外のカラムも非表示 |
| パディング計算 | スクロール位置に応じた上部/下部パディング |
| リサイズ対応 | コンテナリサイズ変更時に再計算 |

## 分岐ロジック

| 条件 | 処理 |
|------|------|
| 総行数が閾値未満 | 仮想化スキップ、全行レンダリング |
| スクロール位置変更 | 表示範囲を再計算 |
| カラム幅変更 | 水平スクロール再計算 |
